# Atlas — Roadmap

## Phase 1 (Current)
- Recursive `package.json` parser.
- Workspace dependency mapper and DFS dependent tracer.

## Phase 2 (Planned)
- Support for `Cargo.toml` and `go.mod` files.
- Visual dependency graph exporter (Mermaid output).

## Phase 3 (Future)
- Monorepo task execution caching (build orchestration tool).
